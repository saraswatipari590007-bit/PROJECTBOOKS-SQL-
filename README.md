# 📚 Bookstore Database Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing a bookstore database using SQL to retrieve meaningful information about books, customers, and orders. It demonstrates practical SQL querying skills through data filtering, aggregate functions, and database analysis using MySQL/SQL.

## 🎯 Objectives
- Retrieve all books belonging to the Fiction genre.
- Calculate the total number of Fiction books using `COUNT()`.
- Identify books published after 1950.
- Retrieve customers who are from Canada.
- Filter orders placed during November 2023 using date-based SQL queries.

## 🛠️ Technologies Used
- **SQL**
- **MySQL**
- Relational Database Queries

## 🔍 SQL Concepts Practiced
- `SELECT` statements to retrieve records.
- `WHERE` clauses to filter data.
- `COUNT()` and aggregate functions to summarize records.
- Comparison operators for filtering publication years.
- Date filtering to analyze monthly orders.
- Database and table creation for organizing data.

## 📊 Key Learning Outcomes
- Extract specific information from a bookstore database.
- Apply filtering conditions to books, customers, and orders.
- Calculate category-based book counts.
- Work with publication years and order dates.
- Develop practical SQL skills for data analysis.

## 💼 Skills Demonstrated
SQL Querying | Data Filtering | Aggregate Functions | Date-Based Analysis | MySQL Database Management

## 🚀 Project Purpose
This project is part of my Data Analytics learning journey and demonstrates how SQL can be used to explore relational databases and answer real-world business questions in the bookstore industry.
